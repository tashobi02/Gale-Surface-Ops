## Production & compliance rules

1. **No human / under-18 likeness:** screen capture only (browser `1440×900` OPS/Planner/Print and `844×390` EVA tablet / HUD frames).
2. **English subtitles:** generated directly into `.srt` and burned into H.264 `.mp4` outputs by [scripts/make_video.sh](../../scripts/make_video.sh) ([FD-162](../plan/frontend/decisions.md)).
3. **Narration guardrails:** read numeric figures strictly from the screen ([FD-043](../plan/frontend/decisions.md)); never describe solar events as "live" ([FD-217](../plan/frontend/decisions.md)); include NASA **and ESA** datasets on camera; omit unbuilt layers (CRISM L5, REMS, MARCI L12 per [credits.md](credits.md#not-built-so-not-credited)).
4. **Narration audio status:** this Linux environment lacks macOS `say` ([FD-165](../plan/frontend/decisions.md)) and local CLI TTS engines; `scripts/make_video.sh` burns English subtitles cleanly and synthesizes audio automatically when run on macOS (`say`) or a host with a supported TTS binary.
