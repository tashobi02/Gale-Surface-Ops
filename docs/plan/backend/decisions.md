Each row below closes one open `TODO(decision)`, `TODO(verify)` or Unresolved U- item in the backend scope. Rules applied to every row:

- **No invented science numbers.** A value comes from the data, the pipeline or `packages/compute`; where a value has no source it is computed, or it is labelled `assumed` and stored in a ParamSet with a source note. No row introduces a bare literal.
- **Requirement text is changed only where the decision needs it**, and only through [02-spec-changes.md](02-spec-changes.md) (labels stay; new text is marked Proposed with the attribution below).
- **"Ratify"** means: the behaviour already implemented on `main` (and named in the cell) becomes the decided rule; the implementer replaces the marker with a reference to the decision id, and adds a test where the cell asks for one.
- **Verification replaces sign-off.** Wherever a subtask asked for a second person, a human sign-off or a hand check, the decision is the automated check named in the work package plus the final review in [99-verification.md](99-verification.md).

Attribution used in the last column, written out in full on every row as required: *decided by the orchestrator (Claude) under Sadman Shaharier Mahim's authority, 12 Nov 2026*.
