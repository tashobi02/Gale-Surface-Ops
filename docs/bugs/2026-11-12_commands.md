## Recording method

Checks ran from the repository root unless the command changes directory. A Python subprocess wrapper captured stdout/stderr and the command's exit code to `/tmp/marswalk-system-test/commands.jsonl`. Each command below ran separately, even when a tool call batched several commands. Shell `rg` exit 1 means no match, not a failed invariant. The wrapper's own invocation is not counted as a second test. Initial `pwd` and `cat CLAUDE.md docs/README.md docs/tasks/_coordination.md docs/tasks/status.md` both exited 0 before the recorder was created; that large read was truncated in the display and followed by targeted reads/inventory.

Scratch helper construction and report/ledger generation used shell heredocs and Python file writes (exit 0); these are administrative artifact operations, not additional product checks. Early source reads and script revisions are retained below, including failed exploratory probes. Their failures are not promoted to product bugs without a corrected reproduction. Temporary helper paths are local evidence; the delivered reproduction script has portable repo-root commands in the report.
